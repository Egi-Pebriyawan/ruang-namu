## Responsive Rules

- Use mobile-first approach (default styles for mobile)
- Use Tailwind breakpoints:
  - sm (640px)
  - md (768px)
  - lg (1024px)
  - xl (1280px)
- Layout must adapt for:
  - Mobile (stacked layout)
  - Tablet (semi-grid)
  - Desktop (multi-column)
- Avoid fixed widths (use w-full, max-w-\*)
- Use responsive spacing (px-4 md:px-8 lg:px-12)
