# UI & Design Guidelines

## 1. Color Palette (Tailwind)

- Primary Background: bg-stone-50
- Coffee Accent: text-amber-900 (espresso), text-amber-600 (caramel)
- Body Text: text-stone-700

## 2. Typography

- Headings: 'Playfair Display', serif
- Body: 'Inter', sans-serif

## 3. Layout Rules

- Use max-width container: max-w-7xl mx-auto px-6
- Section spacing: py-20

## 4. Component Styling

- Cards: rounded-2xl shadow-sm p-6 bg-white
- Buttons:
  - Primary: bg-amber-900 text-white hover:bg-amber-800
  - Secondary: border border-amber-900 text-amber-900
- Navbar:
  - bg-white/70 backdrop-blur-md sticky top-0 z-50

## 5. Interactions

- Use transition-all duration-300
- Add hover scale: hover:scale-105 (for cards/images)

## 6. UX Rules

- CTA buttons must be visible without scrolling
- Use consistent spacing and alignment
